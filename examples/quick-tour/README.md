# 第一次试用 PaperMirror

`main.tex` 是一小段教材风格的线性回归介绍，包含输入特征、线性预测、均方误差和梯度下降。它使用通用的学术表达，适合第一次认识 PaperMirror 的读者。内容专为演示编写，不涉及作者的论文、研究数据或实验结果。配置好翻译接口后，打开文件并运行 `PaperMirror: Open Preview`。

按这个顺序试一下：

1. 先不修改。对照左边的英文、右边的中文，看源码中的公式怎样显示。
2. 把 `stochastic gradient descent` 改成 `mini-batch gradient descent`，保存。右侧对应的中文术语刷新，这段会留下 `Edited` 标记。
3. 点 `Show before`，对照修改前的中文。不需要一直盯着翻译过程，也能回头检查。
4. 将公式左侧改成 `\mathcal{L}`，右侧加入 `+ \lambda\|\mathbf{w}\|_2^2`，并补一句正则项的含义。展开公式旁的 `Show before`，看两版公式的区别。`revised.tex` 提供完整的修改后版本，便于照着操作。
5. 检查完点 `Clear marks`，从当前内容开始记录下一轮变化。它只清除标记，不会撤销刚才的修改。

录制时先展示已有的中文与公式，再修改文字，最后修改公式。无需在演示里介绍配置项、API、缓存或调试信息。

`revised.tex` 是修改脚本的参考。要看到持续标记，应在已经打开预览的 `main.tex` 中修改并保存；直接切换到另一个文件会建立该文件自己的对比起点。

这些内容只用于演示，没有虚构实验数据或方法创新。实际翻译由你配置的模型完成，中文措辞可能不同。首页的 [8 秒演示](../../media/quick-tour.gif)使用固定示例译文，由真实 VS Code 操作画面剪成；播放节奏不代表实际接口耗时。
